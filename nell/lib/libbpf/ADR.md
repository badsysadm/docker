# ADR: libbpf — профиль NELL

## Статус

Принято.

## Контекст

Suricata использует libbpf; статический архив необходим для отказа от динамической зависимости.

## Решение

Для статической и разделяемой сборки libbpf использовать штатный src/Makefile и существующие профили elfutils и zlib.

## Последствия

Статический архив доступен другим профилям NELL, разделяемая библиотека остаётся в итоговом артефакте.

## Рассмотренные альтернативы

Использование Debian-библиотеки отклонено для Suricata из-за обнаруженной динамической зависимости.
