# ADR: libjansson — профиль NELL

## Статус

Принято.

## Контекст

Suricata использует libjansson; статический архив необходим для отказа от динамической зависимости.

## Решение

В upstream CMake одна конфигурация создаёт только один тип библиотеки. Локальный patch добавляет параллельную статическую цель `jansson_static`, сохраняя штатную цель `jansson` для разделяемой библиотеки, её версионирование символов и CMake export; обе библиотеки устанавливаются за один проход. Upstream-пример остаётся доступен без сборки тестовых и документационных целей.

## Последствия

Статический архив доступен другим профилям NELL, разделяемая библиотека остаётся в итоговом артефакте.

## Рассмотренные альтернативы

Использование Debian-библиотеки отклонено для Suricata из-за обнаруженной динамической зависимости.
