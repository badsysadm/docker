# ADR: libnet — профиль NELL

## Статус

Принято.

## Контекст

Suricata использует libnet; статический архив необходим для отказа от динамической зависимости.

## Решение

Сохранить штатный libnet-config. Документация Doxygen не входит в сборку.

Размещать функции и данные в отдельных секциях (`-ffunction-sections`, `-fdata-sections`), чтобы статически линкующие libnet потребители могли исключать неиспользуемые секции с `--gc-sections`.

## Последствия

Статический архив доступен другим профилям NELL, разделяемая библиотека остаётся в итоговом артефакте.

## Рассмотренные альтернативы

Использование Debian-библиотеки отклонено для Suricata из-за обнаруженной динамической зависимости.
