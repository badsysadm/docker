# ADR: профиль libbz2

## Статус
Принято.

## Решение
- Использовать upstream Git-тег bzip2 1.0.8.
- Применять `debian/patches/_build.patch`, взятый из Debian bzip2 1.0.8-6 (`debian/patches/makefile.diff`): https://sources.debian.org/patches/bzip2/1.0.8-6/makefile.diff/
- Патч дополняет штатный Makefile сборкой и установкой разделяемой библиотеки и поддержкой флагов компиляции.
- Собирать `libbz2.a` и `libbz2.so` с PIC, устанавливать через штатный `make install`.
- Не запускать тесты; удалять установленные CLI и документацию из `/src/target`, сохраняя библиотеки и заголовок.

## Последствия
- Статический архив и разделяемая библиотека доступны зависимым профилям NELL.
- Debian-патч необходимо проверять при обновлении версии upstream.
