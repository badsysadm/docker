# ADR: libmaxminddb — профиль NELL

## Статус

Принято.

## Контекст

Suricata использует libmaxminddb; статический архив необходим для отказа от динамической зависимости.

## Решение

Раздельные CMake-сборки необходимы, поскольку upstream переключает тип библиотеки через BUILD_SHARED_LIBS. Утилита mmdblookup собирается в статической конфигурации и устанавливается вместе с библиотеками.

## Последствия

Статический архив доступен другим профилям NELL, разделяемая библиотека остаётся в итоговом артефакте.

## Рассмотренные альтернативы

Использование Debian-библиотеки отклонено для Suricata из-за обнаруженной динамической зависимости.
