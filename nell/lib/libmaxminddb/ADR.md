# ADR: libmaxminddb — профиль NELL

## Статус

Принято.

## Контекст

Suricata использует libmaxminddb; статический архив необходим для отказа от динамической зависимости.

## Решение

Upstream CMake использует единственную цель, тип которой переключается через `BUILD_SHARED_LIBS`. Локальный patch добавляет статическую цель `maxminddb_static` рядом со штатной разделяемой `maxminddb`, сохраняя публичные заголовки, стандартные имена библиотек и исходную CMake export-цель `maxminddb::maxminddb`. `mmdblookup` линкуется с `maxminddb_static`. Оба формата библиотеки и утилита собираются и устанавливаются за один проход.

## Последствия

Статический архив доступен другим профилям NELL, разделяемая библиотека остаётся в итоговом артефакте.

## Рассмотренные альтернативы

Использование Debian-библиотеки отклонено для Suricata из-за обнаруженной динамической зависимости.
