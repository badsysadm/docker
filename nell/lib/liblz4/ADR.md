# ADR: Сборка liblz4 без утилит

## Статус

Принято.

## Контекст

Suricata использует API библиотеки LZ4 для сжатия PCAP. Upstream LZ4 предоставляет раздельные цели для сборки библиотеки и командных утилит.

## Решение

Собирать только библиотечные артефакты через upstream `lib/Makefile`, не включая CLI. Сохранять статический и разделяемый варианты библиотеки, публичные заголовки и pkg-config metadata. Статический архив собирать с PIC.

## Последствия

Зависимые профили могут получать статический архив из NELL без переноса разделяемой библиотеки. Командные утилиты LZ4 профиль не поставляет.

## Рассмотренные альтернативы

Полная сборка верхнеуровневой цели отклонена, поскольку она включает не требующиеся библиотечному профилю CLI и дополнительные цели.
