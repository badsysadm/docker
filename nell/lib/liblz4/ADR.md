# ADR: Сборка LZ4 с библиотеками и CLI

## Статус

Принято.

## Контекст

Suricata использует API библиотеки LZ4 для сжатия PCAP. Upstream LZ4 предоставляет раздельные цели для сборки библиотеки и командных утилит.

## Решение

Использовать штатные цели upstream для сборки библиотек и CLI. Сохранять статический и разделяемый варианты библиотеки, публичные заголовки, pkg-config metadata и утилиту `lz4` с её стандартными именами. Статический архив собирать с PIC. Устанавливаемые upstream man-страницы удалять из целевого образа.

## Последствия

Зависимые профили могут получать статический архив из NELL без переноса разделяемой библиотеки. В итоговом образе устанавливаются `lz4`, `lz4c`, `lz4cat` и `unlz4`.

## Рассмотренные альтернативы

Общая цель `all` включает тесты и документацию и потому не используется. Штатные release-цели для библиотеки и CLI позволяют собрать пользовательские артефакты без этих дополнительных целей.
