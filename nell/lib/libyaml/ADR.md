# ADR: libyaml — профиль NELL

## Статус

Принято.

## Контекст

Suricata использует libyaml; статический архив необходим для отказа от динамической зависимости.

## Решение

Собирать библиотеку через Autotools, устанавливая штатные заголовки и pkg-config без рекурсивной сборки каталога tests.

## Последствия

Статический архив доступен другим профилям NELL, разделяемая библиотека остаётся в итоговом артефакте.

## Рассмотренные альтернативы

Использование Debian-библиотеки отклонено для Suricata из-за обнаруженной динамической зависимости.
