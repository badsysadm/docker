# ADR: Библиотечная сборка xxHash

## Статус

Принято.

## Контекст

Suricata требует статическую библиотеку xxHash, отсутствующую в используемом Debian-окружении. Upstream предлагает независимые цели сборки и установки библиотеки и CLI.

## Решение

Использовать библиотечные цели upstream Makefile для сборки обоих вариантов библиотеки, установки заголовков и pkg-config metadata, без установки CLI. Статический архив собирать с PIC.

## Последствия

Потребители могут явно копировать статический архив NELL без разделяемой библиотеки. Командная утилита xxhsum не входит в профиль.

## Рассмотренные альтернативы

Сборка и установка через общие цели upstream добавляла бы ненужные CLI и руководство. Использование Debian-архива невозможно в текущем сборочном окружении.
