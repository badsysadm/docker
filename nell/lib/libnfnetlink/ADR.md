# ADR: Использование собственной сборки libnfnetlink

## Статус

Принято.

## Контекст

В используемом окружении Debian пакет `libnfnetlink-dev` не содержит `libnfnetlink.a`. Эта библиотека необходима для статической линковки Suricata.

## Решение

Использовать отдельный профиль libnfnetlink как источник библиотеки и её интерфейсов для зависимых проектов.

Размещать функции и данные в отдельных секциях и включать удаление недостижимых секций при линковке, чтобы потребители статического архива могли исключать неиспользуемый код.

## Последствия

Suricata получает libnfnetlink из NELL, не полагаясь на наличие статического архива в Debian. Версия библиотеки управляется профилем. Эффективность исключения кода зависит от фактических ссылок между секциями и от настроек финальной линковки потребителя.

## Рассмотренные альтернативы

Использование Debian `libnfnetlink-dev` отвергнуто ввиду отсутствия статического архива в целевом окружении.
