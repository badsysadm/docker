# ADR: nghttp2 — профиль NELL

## Решение

nghttp2 выделена из curl в отдельный профиль NELL. Upstream Autotools собирает обе библиотеки (.a и .so) при отключённых приложениях и примерах. Объекты собираются с -fPIC, раздельными секциями функций и данных; линковщик удаляет неиспользуемые секции и скрывает символы статических зависимостей.

## Последствия

curl и Git получают libnghttp2.a из bin/lib/nghttp2; разделяемая библиотека также сохраняется.
