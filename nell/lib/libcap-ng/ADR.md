# ADR: libcap-ng — профиль NELL

## Статус

Принято.

## Контекст

Suricata использует libcap-ng; статический архив необходим для отказа от динамической зависимости.

## Решение

Сохранить стандартные утилиты Linux capabilities и Python bindings, если доступны предусмотренные upstream инструменты; собрать библиотеку в обоих форматах.

## Последствия

Статический архив доступен другим профилям NELL, разделяемая библиотека остаётся в итоговом артефакте.

## Рассмотренные альтернативы

Использование Debian-библиотеки отклонено для Suricata из-за обнаруженной динамической зависимости.
