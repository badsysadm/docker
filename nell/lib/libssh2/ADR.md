# ADR: libssh2 — профиль NELL

## Решение

libssh2 выделена из curl в отдельный профиль NELL и собирается одновременно в статический архив и разделяемую библиотеку через upstream CMake. OpenSSL берётся из существующего профиля NELL. Все объекты собираются с -fPIC; секции функций и данных разделяются для линковочной фильтрации, символы статических зависимостей скрываются при построении shared-библиотеки.

## Последствия

curl и Git потребляют статический архив из bin/lib/libssh2. Публичные символы libssh2 остаются экспортируемыми.
