# ADR: профиль сборки ncurses

## Статус
Принято.

## Решение
- Использовать wide-character ncurses.
- Собирать только статические библиотеки, shared-библиотеки не собирать.
- Использовать полную статическую линковку.
- Отключать debug, tests и manpages.
- Генерировать pkg-config files.
- Включать extended colors и extended mouse support.
- Сохранять terminfo в конечном bundle.
- Устанавливать библиотеки в `/lib/x86_64-linux-gnu`, сохраняя совместимость с текущими потребителями.

## Последствия
- Shared ncurses/tinfo библиотеки в bundle отсутствуют.
- Потребители должны использовать статические библиотеки либо предоставлять собственные shared-версии.
- Обновление ncurses требует пересборки статически связанных потребителей.
- Terminfo остаётся доступным runtime-потребителям.
- Документация и тестовые артефакты в конечном bundle отсутствуют.
