# ADR: профиль сборки ncurses

## Статус
Принято.

## Решение
- Использовать wide-character ncurses с extended colors и extended mouse.
- Собирать разделяемые библиотеки, затем обычную статическую модель из отдельных build-каталогов одного дерева исходников.
- Устанавливать утилиты из статической модели: ncursesw встраивается в бинарники, libc остаётся динамической.
- Не выделять terminfo в отдельную библиотеку.
- Устанавливать библиотеки в /usr/lib, утилиты в /usr/bin и экспортировать pkg-config metadata.
- Сохранять скомпилированную базу terminfo для runtime-потребителей.

## Последствия
- Потребители могут статически линковать libncursesw.a без отдельной libtinfo.a.
- Динамические библиотеки предоставляются отдельно для приложений, которым они нужны.
- Обновление ncurses требует пересборки статически связанных потребителей.
