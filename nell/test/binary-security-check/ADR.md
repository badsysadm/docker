# ADR: Фиксация версии binary-security-check

## Статус

Принято.

## Контекст

Upstream переместил основной репозиторий на Codeberg.
Доступный на GitHub репозиторий содержит версионированный тег
`v1.3.1` и соответствующий `Cargo.lock`.

## Решение

Для указанного GitHub-источника закрепить тег `v1.3.1`,
не использовать изменяемую ветку `master`.

## Последствия

Профиль фиксирует версию GitHub-зеркала; обновления основной
разработки на Codeberg не подтягиваются автоматически.
