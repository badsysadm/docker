# ADR: Генерация shell completions для Hyperfine

## Статус

Принято для проверки сборкой.

## Контекст

Upstream `build.rs` создаёт shell completions в `OUT_DIR` по умолчанию.
Этот внутренний каталог не входит в устанавливаемые артефакты.

## Решение

- Задать `SHELL_COMPLETIONS_DIR` при сборке, чтобы сохранить файлы
  автодополнения в устанавливаемом каталоге.
- Устанавливать сгенерированные файлы в
  `/usr/share/hyperfine/completions`.

## Последствия

Shell completions поставляются вместе с исполняемым файлом без отдельного
запуска генератора.

## Альтернативы

- Оставить стандартный `OUT_DIR`: файлы автодополнения не попадут
  в конечный bundle.
