# ADR: binsider with offline vendored Rust dependencies

## Статус

Принято для проверки сборкой.

## Контекст

binsider — программа на Rust. Правила nell требуют отделить
получение исходников и зависимостей от финальной компиляции,
выполнить статическую линковку сторонних библиотек и оставить
динамической только libc.

## Решение

- Использовать официальный upstream тег `v0.3.2`.
- Использовать Rust `1.88.0` согласно upstream `rust-version`.
- Получать исходники через `git clone` в `01_src`.
- Устанавливать build-зависимости посредством `mk-build-deps`
  по `debian/control`, toolchain и vendor-кеш Rust — только в `02_dep`.
- В `03_bin` собирать `cargo build --offline --locked --release`,
  устанавливать исполняемый файл через `install -D` в `/src/target/usr/bin`.
- Не собирать и не запускать тесты, не собирать документацию.
- Финальный слой — `FROM scratch` с артефактами `/target`.

## Ограничения

- Встроенные зависимости Rust берутся из зафиксированного Cargo.lock.
- Запускаемые программой сторонние инструменты не входят в сборочный артефакт.
- Сборка в целевой среде и соответствие ELF политике линковки
  пока не подтверждены.
