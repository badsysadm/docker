# ADR: Go-реализация checksec

## Статус

Принято.

## Контекст

Upstream checksec содержит историческую Bash-реализацию
`checksec.bash` и современную Go-реализацию CLI с отдельным
набором поддерживаемых форматов вывода.

## Решение

Поставлять современный Go CLI из корня репозитория под именем
`/usr/bin/checksec`, не подменяя его старой Bash-реализацией.

## Последствия

Набор опций и форматов вывода определяется Go-реализацией.
Файл `checksec.bash` не включён в артефакт.
