# ADR: профиль сборки GNU nano

## Статус
Принято для проверки сборкой.

## Контекст
Для компактного пользовательского редактора необходима работа
с терминалом без зависимости от разделяемых библиотек ncurses.

## Решение
- Использовать официальный release tarball GNU nano.
- Линковать широкосимвольную ncursesw и tinfo статически,
  оставляя libc динамической.
- Отключить NLS, сохранив поддержку Unicode через ncursesw.
- Сохранить установленные файлы определения синтаксиса Nano
  для подсветки в терминале.

## Последствия
- У редактора нет зависимости от динамических ncursesw и tinfo.
- Переводы сообщений отсутствуют.
- Для подсветки синтаксиса доступны штатные файлы Nano.

## Альтернативы
- Полностью статическая линковка, как в старой initrd-сборке:
  не применяется из-за требования динамической libc.
