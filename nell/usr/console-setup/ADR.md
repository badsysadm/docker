# ADR: Сборка console-setup для Linux

## Решение

- Использовать штатные цели upstream `build-linux` и `install-linux`, без Debian packaging scripts.
- Устанавливать обычный вариант с `ckbcomp`, а не `mini`: раскладки компилируются по запросу, без предварительного формирования ограниченного набора keymap-файлов.
- Сохранять генерируемые консольные шрифты и таблицы перекодировки; они необходимы для работы `setupcon`.

## Следствия

- `setupcon` и `ckbcomp` являются скриптами; для их выполнения в целевой системе потребуются соответствующие интерпретаторы и утилиты консоли.
- Сборка не содержит предварительно скомпилированных `mini`-раскладок.
