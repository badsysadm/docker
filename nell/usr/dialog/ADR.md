# ADR: профиль сборки dialog

## Статус
Принято.

## Решение
- Собирать из официального архива Invisible Island с обычной TLS-проверкой сертификата.
- Использовать wide-character ncurses.
- Линковать ncursesw из собственного OCI-образа статически, libc оставлять динамической.
- Устанавливать бинарник в `/usr/bin`, библиотеки в `/usr/lib`.
- Собирать и устанавливать `libdialog.a` и `libdialog.so` через libtool (`--with-shared --with-libtool`, `install-lib`).
- Тесты не запускать, документацию удалять.

## Последствия
- Для бинарника `dialog` не требуется динамическая ncursesw; статическая и разделяемая `libdialog` поставляются в bundle.
- Обновление ncurses требует пересборки dialog.
- Сборка зависит от корректной TLS-цепочки upstream-сервера.
