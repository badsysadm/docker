# ADR: Midnight Commander with static GLib and ncurses

## Статус
Принято для проверки сборкой.

## Контекст
Midnight Commander требует GLib и терминальную библиотеку.
Для обеих библиотек существуют профили `nell`.

## Решение
- Использовать официальный upstream Midnight Commander версии 4.8.33.
- Использовать GLib, ncurses и zlib из существующих профилей `nell`.
- Использовать терминальный backend ncursesw, сохранив встроенные редактор,
  просмотрщик, файловые панели и VFS.
- Включить управление атрибутами ext2/ext3/ext4 через Debian `libext2fs-dev` (`libe2p`).
- Отключить X11, GPM и NLS; не включать необязательные SFTP и Aspell.
- Использовать статическую линковку сторонних библиотек, сохранив
  динамическую libc.
- Оставить файлы `/usr/share/mc`, необходимые для работы приложения.

## Последствия
- В терминале работает Midnight Commander без X11 и GPM, с диалогом Chattr.
- Поддержка SFTP не включена; обычные возможности VFS остаются.
- До завершения проверки необходимо подтвердить статическую линковку
  транзитивных зависимостей, содержимое /target и воспроизводимость.
