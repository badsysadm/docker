# ADR: профиль сборки umoci

## Статус
Принято для проверки сборкой.

## Решение
- Получать исходники из официального upstream Git-тега выбранной версии.
- Устанавливать Go toolchain согласно требованиям `go.mod`.
- Собирать штатный `cmd/umoci` с vendored Go-зависимостями без сети в `03_bin.Dockerfile`.
- Использовать `CGO_ENABLED=0`, `-mod=vendor`, `-buildvcs=false`, `-trimpath`, фиксировать upstream commit в штатном поле версии.
- Не запускать тесты и не включать документацию в конечный образ.
- Устанавливать только `/target/usr/bin/umoci` с правами `0755` в финальный `scratch`-образ.

## Последствия
- Исполняемый файл не имеет динамически подключаемых сторонних библиотек.
- Воспроизводимость проверяется командой `make umoci`.
