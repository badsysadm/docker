# ADR: профиль сборки skopeo

## Статус
Принято для проверки сборкой.

## Решение
- Получать исходники из официального upstream Git-тега выбранной версии.
- Устанавливать Go toolchain согласно требованиям upstream `go.mod`.
- Собирать штатный `cmd/skopeo` с vendored Go-зависимостями без сети в `03_bin.Dockerfile`.
- Применять `CGO_ENABLED=0` и теги `containers_image_openpgp`, `exclude_graphdriver_btrfs`, исключая CGO-зависимости.
- Использовать `-mod=vendor`, `-buildvcs=false`, `-trimpath`; не запускать тесты и не собирать документацию.
- Устанавливать только `/target/usr/bin/skopeo` с правами `0755` в финальный `scratch`-образ.

## Последствия
- Использование OpenPGP вместо GPGME и исключение Btrfs graphdriver ограничивают функциональность.
- Upstream предупреждает, что статические сборки skopeo не поддерживаются официально; необходима проверка на целевой ОС.
- Политика доверия и конфигурация контейнерных реестров остаются под управлением целевой ОС.
- Воспроизводимость проверяется командой `make skopeo`.
