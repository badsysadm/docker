# ADR: профиль сборки chrony

## Статус
Предложено.

## Решение
- Собирать штатные chronyd и chronyc с поддержкой NTS.
- Сохранять разрешение DNS-имён NTP-серверов и смену пользователя процесса.
- Оставлять libc динамической из-за DNS/NSS и использовать статические сторонние библиотеки.
- Включать libcap для сброса привилегий и libseccomp для фильтрации системных вызовов.
- Не включать интерактивное редактирование строк chronyc через libedit.

## Последствия
- Для разрешения имён серверов и системного пользователя нужны настройки NSS целевой системы.
- chronyd может использовать NTS и выполнять сброс привилегий.
- chronyc работает без libedit.
