# ADR: curl с TLS, SSH и HTTP/2

## Статус
Принято для проверки сборкой.

## Контекст
Требуется curl для сетевой диагностики и передачи данных с
поддержкой TLS, SSH и HTTP/2. Референсом служит
`bootstrap/debian/curl.Dockerfile`.

## Решение
- Собирать curl, разделяемую и статическую libcurl из официальных исходников.
- Использовать OpenSSL для TLS, libssh2 для SSH/SFTP, nghttp2
  для HTTP/2 и zlib для сжатия.
- Подготавливать эти библиотеки из исходников в стадии зависимостей.
- Сохранять вспомогательный скрипт wcurl из upstream.

## Последствия
- Результат включает curl, wcurl, libcurl.so, libcurl.a и её заголовки.
- Возможности, использующие libpsl, Brotli и Zstandard, не включены.
- Для wcurl необходимы стандартные утилиты командной оболочки.

## Альтернативы
- Использовать динамические библиотеки из Debian: не выбрано
  из-за требования самодостаточной линковки сторонних зависимостей.
