# ADR: curl с TLS, SSH, HTTP/2 и сжатием

## Статус
Принято для проверки сборкой.

## Контекст
Требуется curl для сетевой диагностики и передачи данных с
поддержкой TLS, SSH, HTTP/2 и сжатия. Референсом служит
`bootstrap/debian/curl.Dockerfile`.

## Решение
- Собирать curl, разделяемую и статическую libcurl из официальных исходников.
- Использовать OpenSSL для TLS, libssh2 для SSH/SFTP, nghttp2
  для HTTP/2, zlib и Zstandard для сжатия.
- Использовать готовые артефакты OpenSSL, zlib и Zstandard из профилей nell.
- Подключать статическую Zstandard через штатную поддержку curl.
- Собирать libssh2 и nghttp2 из upstream-исходников, полученных на стадии 01.
- Сохранять вспомогательный скрипт wcurl из upstream.

## Последствия
- Результат включает curl, wcurl, libcurl.so, libcurl.a и её заголовки.
- Возможности, использующие libpsl и Brotli, не включены.
- Для wcurl необходимы стандартные утилиты командной оболочки.

## Альтернативы
- Использовать динамические версии сторонних библиотек: не выбрано
  для сохранения независимости от их разделяемых объектов.
