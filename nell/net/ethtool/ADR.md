# ADR: профиль сборки ethtool с Netlink

## Статус
Принято для проверки сборкой.

## Контекст
Современные операции ethtool используют Netlink через libmnl.

## Решение
- Сохранить Netlink и расширенное декодирование регистров, EEPROM и SFP.
- Статически линковать libmnl из Debian, не отключая Netlink.

## Последствия
- Сохранены команды ethtool, работающие через Netlink.
- Динамическая libmnl для запуска не требуется.

## Альтернативы
- Отключить Netlink: не выбрано из-за потери доступных через него операций.
