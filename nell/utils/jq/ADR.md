# ADR: профиль сборки jq

## Статус
Принято для проверки сборкой.

## Контекст
Для обработки JSON необходим CLI jq с полноценной поддержкой
регулярных выражений.

## Решение
- Использовать официальный release tarball jq.
- Использовать встроенный в исходный архив Oniguruma, собираемый
  как статическая библиотека.
- Отключить разделяемые библиотеки и сборку документации.
- Устанавливать только исполняемый файл `jq`.

## Последствия
- Поддерживается работа с регулярными выражениями jq.
- Oniguruma включён в исполняемый файл, отдельная
  динамическая библиотека не требуется.
- При обновлении встроенного Oniguruma потребуется пересборка jq.

## Альтернативы
- Сборка без Oniguruma: отклонена из-за отсутствия regex-функций.
