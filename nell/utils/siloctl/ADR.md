# ADR: профиль сборки Silo Client

## Статус
Принято для проверки сборкой.

## Контекст
Оригинальный MinIO Client более не развивается. PGSTY поддерживает
форк `pgsty/mc` под именем `mcli`, совместимый с Silo и
S3-совместимыми объектными хранилищами.

## Решение
- Использовать поддерживаемый форк `pgsty/mc` вместо архивного `minio/mc`.
- Назвать проект `siloctl` и устанавливать его единственный
  исполняемый файл как `/usr/bin/siloctl`, не добавляя алиасы
  `mc` или `mcli`.
- Сохранить upstream build tag `kqueue` для совместимости сборки.

## Последствия
- Команды клиента доступны через `siloctl`; интерфейс CLI и
  пользовательские настройки наследуются от `pgsty/mc`.
- Для работы с TLS-хранилищами потребуется системный набор
  доверенных сертификатов в целевой ОС.
