# ADR: профиль сборки XZ Utils

## Статус
Принято.

## Решение
- Собирать из upstream release-тега через CMake.
- liblzma собирать статически, shared-библиотеки отключать.
- Отключать NLS, XZ docs и Doxygen.
- Тесты не запускать, установленную документацию удалять.

## Последствия
- Shared liblzma не предоставляется этим bundle.
- Проекты, использующие liblzma, должны линковать статический архив либо предоставлять свою shared-версию.
- Обновление liblzma требует пересборки статически связанных потребителей.
