# ADR: профиль сборки quota

## Статус
Предложено.

## Решение
- Собирать утилиты для управления локальными дисковыми квотами.
- Не включать RPC/rquotad и интеграцию с LDAP.
- Не включать quota_nld и обработку уведомлений через netlink/D-Bus.
- Не использовать libwrap.
- Не включать прямое чтение ext2/ext3/ext4 через libext2fs (ext2direct).

## Последствия
- Управление локальными квотами выполняется через системный quota API.
- Удалённое обслуживание квот через RPC недоступно.
- Уведомления о квотах через quota_nld недоступны.
- Сканирование ext-файловых систем через libext2fs недоступно.
