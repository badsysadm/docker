# ADR: профиль сборки gawk

## Статус
Принято.

## Решение
- Собирать gawk 5.4.1 из официального GNU release tarball.
- Сохранять параметры рабочей сборки из `bootstrap/debian/gawk.Dockerfile`.
- Использовать layout `/usr`, `/etc`, `/var`, `/sbin`, `/usr/lib64`.
- Отключать NLS.
- Тесты не запускать.
- Удалять man, info и doc из конечного bundle.

## Последствия
- Локализация и документация в bundle отсутствуют.
- Пути установки закреплены текущими configure-флагами.
- При изменении upstream build system необходимо отдельно проверить сохранение этих параметров и отсутствие новых runtime-зависимостей.
