# ADR: профиль сборки GNU grep

## Статус
Принято для проверки сборкой.

## Контекст
Для поиска текста необходимы стандартные выражения BRE и ERE, а
также режим Perl-совместимых регулярных выражений `grep -P`.

## Решение
- Использовать официальный GNU release tarball.
- Сохранять PCRE2 для поддержки `grep -P`, включая
  статическую линковку `libpcre2-8`.
- Отключить NLS, сохранив поиск в UTF-8 и другие
  возможности обработки многобайтовых строк.

## Последствия
- Доступен режим `grep -P` без динамической зависимости от PCRE2.
- Переводы сообщений отсутствуют.
- При обновлении PCRE2 требуется пересборка grep.

## Альтернативы
- Исключить PCRE2: отвергнуто, поскольку пропадёт `grep -P`.
