# ADR: профиль сборки wipe

## Статус
Принято.

## Решение
- Собирать wipe 0.24 из upstream Git-тега `v0.24`.
- Использовать upstream Linux build profile.
- Собирать `wipe` полностью статически.
- Тесты не запускать.
- В конечный bundle устанавливать только `/usr/bin/wipe`.

## Последствия
- `wipe` не имеет shared runtime-зависимостей.
- Документация в конечном bundle отсутствует.
