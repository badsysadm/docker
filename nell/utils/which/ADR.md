# ADR: профиль сборки GNU which

## Статус
Принято для проверки сборкой.

## Контекст
Необходима самостоятельная утилита определения путей исполняемых
команд в `PATH`.

## Решение
- Использовать официальный релизный архив GNU which.
- Собирать штатную реализацию на C, а не заменять её shell-скриптом.
- Устанавливать исполняемый файл `which` в `/usr/bin`.

## Последствия
- Доступна самостоятельная утилита `which` без зависимости от shell-реализаций.
- Сторонние библиотеки для статической линковки не требуются.

## Альтернативы
- Shell-скрипт на основе `type`: не выбран, поскольку его поведение
  и поддерживаемые параметры отличаются от GNU which.
