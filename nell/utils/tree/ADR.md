# ADR: tree 2.3.2

## Статус
Принято для проверки сборкой.

## Контекст
Для просмотра дерева каталогов нужна компактная утилита tree,
собранная по единым правилам nell.

## Решение
- Использовать официальный Git-репозиторий unix-tree и тег 2.3.2.
- Получать исходники командой `git clone --single-branch --depth 1`.
- Собирать штатным `make` без `configure`; upstream не требует
  сторонних библиотек помимо libc.
- Сохранить динамическую libc, не включать дополнительные shared-библиотеки.
- Сохранить штатные функции tree, включая форматированный вывод,
  JSON, XML и HTML, без отключения функциональности.
- Устанавливать только бинарник в `/target/usr/bin/tree`:
  upstream Makefile использует `DESTDIR` как полный путь установки
  бинарника, а не как staging root. Документация не включается.
- Тесты не собирать и не запускать.

## Последствия
- Конечный образ содержит только исполняемый файл tree.
- Через `ldd` необходимо подтвердить отсутствие динамических
  зависимостей кроме libc и загрузчика.
- До принятия сборки проверить `make tree` и воспроизводимость SHA-256.
