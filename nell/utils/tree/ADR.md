# ADR: Ручная установка tree в staging-каталог

## Статус

Принято.

## Контекст

В upstream Makefile переменная `DESTDIR` задаёт каталог установки
исполняемого файла, а не корень staging-дерева. Поэтому обычный вызов
`make install DESTDIR=/src/target` не формирует требуемый путь
`/src/target/usr/bin/tree`.

## Решение

Устанавливать собранный исполняемый файл непосредственно в staging-каталог
через `install -Dm755`, не используя upstream-цель `make install`.
Так путь размещения определяется профилем, а не нестандартной семантикой
`DESTDIR` у upstream.

## Последствия

- Исполняемый файл попадает в ожидаемую структуру staging-каталога.
- Установка не использует upstream-цель `install`; при изменении
  состава устанавливаемых артефактов потребуется пересмотреть этот выбор.

## Рассмотренные альтернативы

- Использовать `make install` с переопределением `DESTDIR` и `MANDIR`.
  Отклонено: для единственного требуемого исполняемого файла это
  усложняет управление путями установки.
