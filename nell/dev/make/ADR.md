# ADR: GNU Make без интеграции Guile

## Статус
Принято для проверки сборкой.

## Контекст
Встраивание GNU Guile в Make требует дополнительных библиотечных
зависимостей, для которых в nell нет готового статического профиля.

## Решение
- Не включать необязательную интеграцию GNU Guile.

## Последствия
- Функции Make, зависящие от Guile, недоступны.

## Альтернативы
- Включить Guile: потребует отдельной сборки её статических зависимостей.
