# ADR: компактная сборка Git с HTTPS

## Статус
Принято для проверки сборкой.

## Контекст
Для разработки необходимы обычные операции с репозиториями, включая
клонирование, получение и отправку изменений по HTTPS.
При этом множество команд Git реализованы внутри одного исполняемого
файла и обычно устанавливаются также под отдельными именами.

## Решение
- Сохранить основной Git, шаблоны и вспомогательные команды для локальной работы, SSH и HTTPS.
- Использовать штатные `INSTALL_SYMLINKS` и `NO_INSTALL_HARDLINKS` вместо hardlinks для устанавливаемых команд.
- Включить `SKIP_DASHED_BUILT_INS`, поскольку встроенные команды вызываются как `git <command>`; необходимые отдельные серверные команды Git сохраняются.
- Отключить Tcl/Tk, переводы, gitweb, Python/Perl-зависимые дополнения, необязательную поддержку Rust и устаревший WebDAV HTTP push.
- Сохранить HTTPS через libcurl со статической линковкой его зависимостей; криптографические примитивы самого Git использовать встроенные, не добавляя отдельную связь с OpenSSL.
- Применять оптимизацию на размер, удаление неиспользуемых секций и strip для исполняемых файлов.

## Последствия
- Предусмотрены работа с локальными репозиториями, SSH и HTTPS.
- Недоступны дополнения, требующие Perl, GUI, gitweb и старый WebDAV HTTP push.
- Компактность и отсутствие динамических зависимостей, кроме libc, требуют проверки результатом сборки.

## Альтернативы
- Отказаться от libcurl ради минимального бинарника: не выбрано, поскольку пропадёт поддержка HTTPS.
