# ADR: Automake с Autoconf из nell

## Статус
Принято для проверки сборкой.

## Контекст
Automake устанавливает сценарии Perl и поддерживающие шаблоны и макросы.
Его configure проверяет наличие исправного Autoconf.

## Решение
- Использовать при конфигурации Autoconf и GNU M4 из профилей nell.
- Сохранять исполняемые сценарии, макросы и шаблоны Automake,
  включая версионированные каталоги данных.

## Последствия
- Для работы Automake в целевой среде необходимы Perl и Autoconf.
- Удаление шаблонов и макросов сделало бы генератор Makefile.in
  неполнофункциональным.

## Альтернативы
- Собирать с системным Autoconf Debian: не выбрано,
  поскольку готовый профиль nell обеспечивает согласованность инструментов.
