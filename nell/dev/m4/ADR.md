# ADR: Обработка переполнения стека в GNU m4

## Статус
Принято для проверки сборкой.

## Контекст
GNU m4 допускает внешний libsigsegv либо встроенную реализацию gnulib.

## Решение
- Оставить штатный обработчик переполнения стека gnulib без
  дополнительной зависимости от libsigsegv.

## Последствия
- Не требуется отдельная статическая библиотека libsigsegv.

## Альтернативы
- Внешняя libsigsegv: не выбрана, поскольку gnulib уже предоставляет
  обработку на целевой платформе Linux.
