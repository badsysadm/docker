# ADR: Lintian с PAR::Packer

## Статус
Предложено; сборка и работа с пакетом ещё не проверены.

## Контекст
Lintian — Perl-программа, однако его проверки и профили обнаруживаются
динамически по файлам в базовом каталоге. Простой `pp -B bin/lintian`
не охватывает ни динамически загружаемые модули, ни базы правил.

## Решение
- Получать исходники `lintian 2.142.0` из официального репозитория Debian Salsa по Git-тегу версии (`--single-branch --branch --depth 1`).
- Собрать основной исполняемый файл `lintian` через `pp -B`, по аналогии
  с профилями `equivs`, `devscripts` и `debhelper`.
- Явно включать модули из `lib/Lintian` посредством `-M`.
- Сохранять `lib`, `data`, `tags`, `profiles`, `vendors`,
  `private` и `commands` в `/usr/share/lintian`: это runtime-данные.
- Направить `LINTIAN_BASE` в установленный каталог `/usr/share/lintian`.
- Использовать фиксированное время и настройки Perl для повторяемости
  упаковки PAR. Не собирать тесты и документацию.

## Ограничения и дальнейшая проверка
- Это стартовый профиль, а не подтверждённая рабочая сборка.
- До признания профиля готовым проверить загрузку всех проверок,
  динамических модулей и вспомогательных процессов `private/`.
  Вспомогательные Perl-скрипты и внешние утилиты могут потребовать
  отдельной упаковки; наличие только PAR-бинарника не гарантирует
  автономность всех проверок.
- Требуется проверка на реальном Debian `.deb` и анализ зависимости
  итогового бинарника и встроенных XS-модулей; `ldd` на PAR-файле
  не показывает зависимости распаковываемых расширений.
- Подтвердить воспроизводимость SHA-256 двух сборок.
- Состав `Build-Depends` требует уточнения по фактическим ошибкам
  сборки с учётом версии Debian в окружении.
