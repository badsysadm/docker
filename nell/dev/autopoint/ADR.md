# ADR: Выделение autopoint из GNU Gettext

## Статус
Принято для проверки сборкой.

## Контекст
`autopoint` — часть GNU Gettext: для работы ему нужны не только
исполняемый скрипт, но и архивы инфраструктуры под `share/gettext`.
Повторная компиляция Gettext ради одного инструмента не нужна.

## Решение
- Использовать собранный образ `bin/dev/gettext` как источник
  `autopoint` и его установленных вспомогательных данных.
- Сохранять файлы совместно, чтобы версии скрипта и архивов совпадали.

## Последствия
- Сборка профиля требует готового образа GNU Gettext.
- При обновлении Gettext оба профиля должны использовать одну версию.

## Альтернативы
- Извлечение `autopoint` непосредственно из исходников: отклонено,
  поскольку его вспомогательные архивы формируются при сборке Gettext.
