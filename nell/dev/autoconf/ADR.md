# ADR: Autoconf как набор скриптов и макросов

## Статус
Принято для проверки сборкой.

## Контекст
Autoconf устанавливает исполняемые сценарии и данные M4, а не ELF-бинарник.
Для работы ему необходимы интерпретатор Perl и GNU M4.

## Решение
- Сохранять штатные исполняемые сценарии, M4-макросы и Perl-модули
  в установочных каталогах Autoconf.
- Для конфигурации сборки использовать GNU M4 из профиля nell/dev/m4;
  Perl остаётся внешним интерпретатором целевой среды.

## Последствия
- Артефакт не является автономным: запуск требует Perl и GNU M4.
- Удаление каталогов данных Autoconf сделало бы утилиты неработоспособными.

## Альтернативы
- Встраивать Perl и M4 в артефакт Autoconf: не выбрано,
  поскольку эти инструменты поставляются отдельно.
