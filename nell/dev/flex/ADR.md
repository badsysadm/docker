# ADR: Bootstrap Flex из Git и библиотека libfl

## Статус
Принято для проверки сборкой.

## Контекст
Git-исходники Flex не содержат готовых файлов Autotools и сгенерированных
лексера и парсера. При bootstrap необходимы работающие генераторы,
в том числе ранее установленный Flex.

## Решение
- Подготавливать Git-дерево штатным `autogen.sh` и собирать Flex
  с помощью инструментов bootstrap.
- Сохранять совместимость с Lex: команду `flex++`, заголовок
  `FlexLexer.h` и оба варианта `libfl`, которые upstream
  собирает через Libtool.

## Последствия
- Для сборки требуется установленный Flex; конечный генератор
  использует GNU M4 при работе.
- Устанавливаются как статическая, так и динамическая версии
  `libfl`, совместимые с обычной линковкой Lex-программ.

## Альтернативы
- Использовать готовый release-архив с предварительно
  сгенерированными файлами: не выбрано в пользу Git-источника.
