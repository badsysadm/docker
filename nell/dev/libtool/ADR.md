# ADR: Единая поставка Libtool и libltdl

## Статус
Принято для проверки сборкой.

## Контекст
GNU Libtool включает исполняемые инструменты `libtool` и `libtoolize`,
макросы интеграции с Autotools и библиотеку `libltdl` для динамической
загрузки модулей. Библиотека и инструменты исходно разрабатываются
и распространяются вместе, а `libtoolize` использует вспомогательные
файлы, установленные в каталоге данных пакета.

## Решение
- Поставлять инструменты, макросы и `libltdl` одним профилем.
- Сохранять данные `/usr/share/libtool`, необходимые для внедрения
  Libtool в другие проекты.
- Собирать и устанавливать `libltdl` в статическом и динамическом
  вариантах вместе с публичными заголовками.

## Последствия
- Потребителям доступны и CLI-инструменты, и API загрузки модулей.
- Для `libtoolize` не требуется отдельный пакет вспомогательных файлов.

## Альтернативы
- Выделить `libltdl` в отдельный профиль: не выбрано, поскольку
  компоненты поставляются одним upstream и собираются вместе.
