# ADR: Сборка CMake с встроенными библиотеками и собственным OpenSSL

## Статус
Принято для проверки сборкой.

## Контекст
CMake включает несколько сторонних библиотек в официальный релизный
архив и поддерживает самостоятельную сборку через `bootstrap`.
OpenSSL в исходники CMake не входит, но используется для TLS-соединений.

## Решение
- Использовать официальный `bootstrap` с встроенными библиотеками,
  не подменяя их динамическими системными зависимостями.
- Подключать статические `libssl.a` и `libcrypto.a` из профиля
  `nell/security/openssl`, сохраняя поддержку TLS.
- Сохранять штатные инструменты `cmake`, `ctest` и `cpack`,
  а также данные `share/cmake-*`, необходимые для работы CMake.

## Последствия
- Используются встроенные библиотеки официального релиза CMake.
- Поддержка TLS зависит от собственного профиля OpenSSL.

## Альтернативы
- Системные динамические библиотеки: не выбраны из-за контракта `nell`.
- Отключить OpenSSL: не выбрано, поскольку это ограничивает функциональность.
