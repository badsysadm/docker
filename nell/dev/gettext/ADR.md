# ADR: Сборка инфраструктуры GNU Gettext

## Статус
Принято для проверки сборкой.

## Контекст
GNU Gettext объединяет инструменты обработки переводов, библиотечные
компоненты и инфраструктуру для Autotools. Команда `autopoint` и её
архивы поставляются в том же upstream-проекте.

## Решение
- Собирать инструменты и библиотеки из официального релиза GNU Gettext
  в одном профиле.
- Сохранять установленные макросы и архивы инфраструктуры Gettext,
  необходимые `autopoint` и проектам на Autotools.
- Выделять артефакты `autopoint` из уже собранного образа Gettext,
  не компилируя второй раз одни и те же исходники.

## Последствия
- Оба профиля используют одну версию инфраструктуры и не расходятся
  по содержимому архивов.
- Профиль `autopoint` зависит от ранее собранного `gettext`.

## Альтернативы
- Собирать весь исходный пакет повторно ради `autopoint`: отклонено
  из-за ненужного дублирования компиляции.
