# ADR: Самосборка Ninja

## Статус
Принято для проверки сборкой.

## Контекст
Ninja поддерживает сборку через CMake и через собственный Python
bootstrap. Для получения исполняемого файла отдельный CMake-проект
и сторонние библиотеки не нужны.

## Решение
- Использовать штатный `configure.py --bootstrap` и устанавливать
  только полученный исполняемый файл Ninja.

## Последствия
- Сборка не зависит от CMake и предварительно установленного Ninja.

## Альтернативы
- CMake: не выбран, поскольку требует дополнительного генератора
  для сборки одного исполняемого файла.
