# ADR: Meson в виде Python zipapp

## Статус
Принято для проверки сборкой.

## Контекст
Meson реализован на Python и поддерживает установку как Python-пакета
или упаковку в исполняемый zipapp. При обычной Python-установке
требуется сохранять пакет `mesonbuild` и исполняемую точку входа.

## Решение
- Использовать штатный `packaging/create_zipapp.py` для формирования
  одного исполняемого файла `/usr/bin/meson`.
- Не переносить в артефакт отдельную Python-библиотеку `mesonbuild`;
  её код находится внутри zipapp.

## Последствия
- Meson остаётся Python-программой и требует Python в целевой системе.
- Для стандартного backend Ninja требуется доступный исполняемый Ninja.
- Отдельные установочные данные Python-пакета и интеграция с Polkit
  не включаются в артефакт.

## Альтернативы
- Установка через pip: не выбрана, поскольку для отдельного Meson
  достаточно официально поддерживаемого самодостаточного zipapp.
