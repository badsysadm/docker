# ADR: Установка только исполняемого файла GNU Patch

## Статус
Принято для проверки сборкой.

## Контекст
В GNU Patch сборка инструментов и документации управляется через
Autotools, однако конечным результатом профиля является только одна
исполняемая утилита. Для поддержки расширенных атрибутов и сжатых
данных используются сторонние библиотеки.

## Решение
- Собирать библиотечные объекты и программу из штатных каталогов
  `lib` и `src`, устанавливая только `patch`.
- Использовать статическую `zlib` из существующего профиля `nell`
  и статическую `libattr`, не отключая поддержку расширенных
  атрибутов файлов.

## Последствия
- Документация и тестовые инструменты не входят в сборку программы.
- Для линковки необходима статическая версия `libattr`.

## Альтернативы
- Полный `make install`: не выбран, поскольку для одной программы
  нет необходимости устанавливать документацию.
- Отказ от поддержки расширенных атрибутов: не выбран.
