# ADR: Сохранение Yacc-совместимости Bison

## Статус
Принято для проверки сборкой.

## Контекст
Bison устанавливает скелеты генераторов в каталоге данных, а также
предоставляет команду `yacc` и библиотеку совместимости `liby`.
Upstream собирает `liby` только в статическом варианте.

## Решение
- Сохранить штатные скелеты и макросы генератора в `/usr/share/bison`.
- Сохранить совместимость с Yacc, включая `liby.a`, и дополнительно
  собрать `liby.so` из тех же upstream-исходников.

## Последствия
- Генератор поддерживает штатные режимы и шаблоны языков.
- Доступны оба варианта библиотеки совместимости Yacc.
- Для запуска генератора в целевой среде необходим GNU M4.

## Альтернативы
- Отключить Yacc: не выбрано из-за потери совместимости.
