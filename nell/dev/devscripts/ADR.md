# ADR: mk-build-deps через PAR::Packer

## Статус
Принято для проверки сборкой.

## Контекст
В сборочном окружении нужен `mk-build-deps` из Debian devscripts.
Он написан на Perl и использует модули `Dpkg::*`.

## Решение
- Использовать официальный Debian source archive devscripts.
- Упаковать только `scripts/mk-build-deps.pl` через `PAR::Packer`
  в `/usr/bin/mk-build-deps`.
- Явно включить `Dpkg::Changelog::Parse`, загружаемый скриптом
  динамически; остальные Perl-модули собирать через `pp -B`.
- Не собирать тесты и документацию.

## Ограничения
- `mk-build-deps` продолжает вызывать внешние `equivs-build`,
  `dpkg`, `dpkg-architecture`, `apt-cache` и менеджер установки
  (например `apt-get`); PAR не заменяет эти инструменты.
- `PAR::Packer` не гарантирует отсутствие динамических зависимостей
  у исполняемого файла и упакованных XS-модулей. До завершения профиля
  требуется проверить соответствие правилу `nell` о статической
  линковке сторонних библиотек.
- Воспроизводимость и учет встроенных Perl-компонентов в
  `Static-Built-Using` требуют проверки в целевом окружении.
