# ADR: профиль сборки Trivy

## Статус
Принято для проверки сборкой.

## Контекст
Требуется сканер уязвимостей, конфигураций и секретов с поддержкой
локальной файловой системы и контейнерных образов.

## Решение
- Использовать официальный исходный код релизного тега Aqua Security.
- Собирать CLI `trivy` штатным Go toolchain с `CGO_ENABLED=0`.
- Разрешать Go-зависимости и создавать `vendor` на этапе `02_dep`;
  бинарный этап собирать без сети из `vendor`.
- Передавать версию через штатную переменную `pkg/version/app.ver`.

## Последствия
- Результат содержит один исполняемый файл без динамических
  зависимостей на сторонние библиотеки.
- Для сканирования уязвимостей необходима база Trivy, получаемая
  отдельно при запуске или предоставляемая из локального кеша.
- Сертификаты доверенных центров и другие runtime-данные
  предоставляются целевой системой, а не финальным образом сборки.

## Альтернативы
- Поставлять готовый бинарник upstream: не выбрано, поскольку
  профиль должен собирать программу из исходников.
