# ADR: GnuTLS без PKCS#11 и TPM

**Статус:** Предложено

## Контекст

Профиль GnuTLS предназначен для использования TLS и доверенных сертификатов
из файлового хранилища. Поддержка PKCS#11 и TPM вводит дополнительные
интеграции, которые для выбранного профиля не предусмотрены.

## Решение

- Отключить интеграцию с PKCS#11 и TPM.
- Сохранить поддержку TLS 1.3 и доверенных сертификатов из файлового хранилища.

## Последствия

- GnuTLS не зависит от `libp11-kit` для интеграции PKCS#11.
- Недоступны PKCS#11-токены, PKCS#11-хранилища доверия и интеграция с TPM.
- Потребители, которым нужны такие возможности, не смогут использовать
  данный профиль без изменения принятого решения.
- Статическая и динамическая библиотеки предоставляются в соответствии с
  общими правилами NELL.

## Рассмотренные альтернативы

Не задокументированы.
