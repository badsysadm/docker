# ADR: cracklib

## Решение

- Собирать CrackLib 2.10.3 из официального release-архива upstream.
- Использовать штатную autotools-сборку, без Python bindings и переводов.
- Собирать `libcrack.a` и `libcrack.so` (`--enable-static --enable-shared`) для статической линковки утилит и использования библиотеки внешними компонентами, включая PAM.
- Сохранять словарные данные, необходимые для проверки паролей; документацию удалять.

## Ограничения

- Команды управления словарём могут использовать внешние системные утилиты.
