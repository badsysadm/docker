# ADR: cracklib

## Решение

- Собирать CrackLib 2.10.3 из официального release-архива upstream.
- Использовать штатную autotools-сборку, без Python bindings и переводов.
- Собирать `libcrack.a` и `libcrack.so` (`--enable-static --enable-shared`).
- Включать zlib статически из собственного модуля `nell/lib/zlib`, используя PIC-версию `libz.a`.
- Линковать исполняемые утилиты со статическими `libcrack.a` и `libz.a`.
- Сохранять `libcrack.so` для использования внешними компонентами, включая PAM.
- Сохранять словарные данные, необходимые для проверки паролей; документацию удалять.

## Ограничения

- Команды управления словарём могут использовать внешние системные утилиты.
