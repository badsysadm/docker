# ADR: Suricata 8.0.8 в NELL

## Статус
Предложено; требуется подтверждение сборкой.

## Контекст
Suricata объединяет C и Rust, использует системные библиотеки для анализа пакетов
и публикует конфигурацию, необходимую для запуска IDS/IPS. NELL требует
офлайн-сборку, статическую линковку сторонних библиотек и воспроизводимый образ.

## Решение
- Использовать официальный git-тег `suricata-8.0.8` и `git clone`.
- Генерировать autotools-файлы через `autoreconf`, не вызывая upstream
  `autogen.sh`, удаляющий `rust/Cargo.lock`.
- Выполнять `cargo vendor --locked` в `02_dep`; в `03_bin` использовать
  только локальные Rust-зависимости.
- Использовать OpenSSL и zlib из существующих NELL-профилей, прочие
  библиотеки из Debian, пока для них нет профилей NELL.
- Сохранить AF_PACKET, анализ pcap и конфигурацию Suricata.
- Включить GeoIP2 (`libmaxminddb`) и определение типов файлов (`libmagic`); базы MaxMind `.mmdb` и сигнатур `magic.mgc` поставляются отдельно как необходимые runtime-данные.
- Включить NFQUEUE (inline IPS), NFLOG и eBPF, включая компиляцию eBPF-объектов (`--enable-ebpf-build`).
- Для eBPF требуются libbpf, libelf, clang/llc; для Netfilter — libnetfilter_queue, libnetfilter_log и libnfnetlink.
- Сторонние библиотеки остаются статическими: наличие `.a` и отсутствие посторонних `DT_NEEDED` необходимо подтвердить на сборке.
- Отключить тесты, Python-утилиты, загрузку правил, AF_XDP,
  DPDK и PF_RING в первоначальном профиле.
- Собирать и устанавливать в `/src/target`; конечный образ `FROM scratch`.
- Проверять `DT_NEEDED` установленных ELF на отсутствие зависимостей
  от динамических сторонних библиотек.

## Последствия
- Предусмотрены IDS, inline IPS через NFQUEUE, NFLOG и eBPF; отдельный режим AF_XDP пока отключён.
- Для работы eBPF необходима поддержка соответствующих механизмов ядра и надлежащие привилегии процесса.
- Правила обнаружения не загружаются при сборке и должны предоставляться отдельно.
- Для работы GeoIP2 необходима база MaxMind DB; для libmagic — совместимая база сигнатур.
- Версии Debian-библиотек и Rust-крейтов для `Static-Built-Using`
  требуется уточнить в целевом окружении; нельзя записывать вымышленные версии.
- При неудовлетворённом условии статической линковки сборка должна завершаться ошибкой.
- Выполнение сборки и проверка воспроизводимости остаются обязательными
  перед переводом PR из Draft.

## Альтернативы
- Архив upstream вместо Git: не выбран, поскольку Git-теги являются
  принятым источником для Git-проектов NELL.
- Включение остальных capture-backend: отложено до появления необходимых
  статических библиотек и подтверждения сборки.
