# ADR: Linux Audit userspace

## Статус
Принято для проверки сборкой.

## Контекст
Нужны демон Linux Audit, инструменты управления правилами и анализа
событий, а также библиотеки для взаимодействия с подсистемой аудита ядра.
Upstream объединяет их в одном дереве исходников.

## Решение
- Собирать исходный userspace-проект Linux Audit целиком, включая auditd,
  auditctl, ausearch, aureport, штатные плагины и библиотеки.
- Сохранять поддержку libcap-ng для управления привилегиями процесса;
  при линковке использовать её статический архив.
- Не подключать специфический для z/OS удалённый LDAP-плагин:
  он требует отдельной инфраструктуры OpenLDAP и не нужен для
  локального аудита Linux.
- Языковые привязки Python и Go не входят в профиль системных утилит;
  интерфейсы нативных библиотек сохраняются.
- Остальные необязательные возможности остаются в конфигурации
  upstream по умолчанию, без самостоятельного расширения функциональности.

## Последствия
- Итоговый профиль содержит как аудит-сервис, так и CLI и библиотеки,
  необходимые другим компонентам системы.
- Удалённый z/OS-плагин и языковые привязки не поставляются.
- Интеграция с системой и возможность динамически загружать плагины
  должны проверяться на итоговых артефактах.

## Альтернативы
- Собирать только auditd и auditctl: отвергнуто, так как нужны также
  инструменты поиска событий, отчётности и интерфейсы библиотек.
