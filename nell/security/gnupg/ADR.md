# ADR: профиль сборки GnuPG

## Статус
Принято.

## Решение
- Собирать GnuPG с закреплёнными версиями libgpg-error, libgcrypt, libassuan, libksba и npth из отдельных NELL-профилей.
- Получать статические библиотеки из OCI-образов `bin/lib/*`, не собирать сторонние библиотеки в профиле GnuPG.
- Использовать статические zlib и bzip2 из собственных NELL-профилей без изменения upstream `configure.ac`.
- Применять отдельные секции функций и данных с `--gc-sections`; явно переключать линковщик на статическую линковку сторонних зависимостей и возвращать динамический режим для libc.
- Отключать NLS, scdaemon, gpgsm и dirmngr; не включать документацию в bundle.

## Последствия
- Библиотеки GnuPG имеют собственные `.a` и `.so` OCI-артефакты.
- Сборки библиотек публикуются независимо и используются GnuPG в закреплённых версиях.
- Отсутствуют scdaemon, gpgsm и dirmngr.
- Статическая линковка проверяется по итоговым ELF-артефактам.
