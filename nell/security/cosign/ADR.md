# ADR: профиль сборки Cosign

## Статус
Принято для проверки сборкой.

## Контекст
Необходим CLI для подписи и проверки OCI-образов и других артефактов.

## Решение
- Использовать официальный релизный тег Sigstore Cosign.
- Собирать основной CLI из исходников с `CGO_ENABLED=0`, как
  предусмотрено upstream для обычного Linux-релиза.
- Подготавливать Go-зависимости на этапе `02_dep` и собирать
  бинарник из `vendor` без сети на этапе `03_bin`.
- Указывать версию в upstream-переменной `gitVersion`.

## Последствия
- Формируется один бинарник `/usr/bin/cosign`.
- Поддержка PIV и PKCS#11, требующая отдельного CGO-варианта,
  в основном бинарнике отсутствует.

## Альтернативы
- Вариант upstream с `pivkey,pkcs11key`: не выбран из-за
  дополнительных CGO- и системных зависимостей.
