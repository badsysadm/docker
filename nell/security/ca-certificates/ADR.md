# ADR: готовый Mozilla CA bundle для OpenSSL

## Статус
Принято для проверки сборкой.

## Контекст
Для TLS-проверки сертификатов необходим стандартный набор доверенных корневых CA.
Полноценная система локального управления доверием пока не требуется.

## Решение
- Использовать готовый PEM-бандл Mozilla Root Store, опубликованный проектом curl.
- Получать датированную ревизию готового бандла, а не преобразовывать certdata.txt и не собирать набор сертификатов из исходников Debian.
- Устанавливать бандл по пути `/etc/ssl/certs/ca-certificates.crt` для использования OpenSSL.

## Последствия
- Артефакт содержит единый PEM-файл без утилит управления и списка отдельных доверенных сертификатов.
- При необходимости локальных изменений бандл можно заменить или отредактировать вручную; штатное выборочное включение/отключение CA не предоставляется.
- PEM-экспорт не переносит некоторые ограничения доверия Mozilla, включая name constraints.

## Альтернативы
- Debian `update-ca-certificates`: отложено как избыточная система управления для поставки готового бандла.
